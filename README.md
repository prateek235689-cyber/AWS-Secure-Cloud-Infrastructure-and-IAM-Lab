# AWS Secure Cloud Infrastructure & IAM Lab

## Overview
This project demonstrates the design and implementation of a
secure AWS cloud environment using identity and access management,
network segmentation, data protection, logging, monitoring, and
least-privilege security principles.

The lab focuses on securing cloud infrastructure against common
misconfigurations while demonstrating practical AWS cloud security
skills.

## Objectives:
- Implement least-privilege IAM access
- Secure the AWS root account with MFA
- Design a segmented AWS VPC
- Deploy and secure EC2 workloads
- Protect sensitive S3 resources
- Enable AWS API activity logging
- Monitor security-relevant events
- Identify and remediate cloud misconfigurations

## AWS Services:
- AWS IAM
- Amazon VPC
- Amazon EC2
- Amazon S3
- AWS CloudTrail
- Amazon CloudWatch
- IAM Access Analyzer
- Amazon GuardDuty / AWS Security Hub

## Security Concepts:
- Principle of Least Privilege
- Identity and Access Management
- Network Segmentation
- Defense in Depth
- Encryption
- Logging and Monitoring
- Cloud Misconfiguration Detection
- Incident Investigation
